# Spatial transcriptomics atlas of pediatric LS and SSc skin
A high-resolution spatial transcriptomic (Visium HD) atlas of pediatric localized scleroderma (LS) and systemic sclerosis (SSc) skin. The analyses pipelines include the single cell segmentation and transformation from 2µm-square to single-cell-level spatial transcriptomics.

Code_segmentation: The code used to do cell segmentations on spatial transcriptomics data (Visium HD) and transform the 2µm square level gene expression to single-cell-level gene expression.

Code_analyses: The code for original analyses.

Code_figures: The code for all main figures.
